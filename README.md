# SeuratDocker

This repository contains the source Dockerfiles for images with CRAN releases of Seurat.

As of tag `6.0.0` and pushes to `develop` and `latest` from Nov 9 2026, Seurat is built under R 4.6.1 under Ubuntu 24.04.5 LTS (Noble Numbat) with base image `rocker/tidyverse:4.6.1` ([reference](https://rocker-project.org/images/versioned/rstudio.html), [source](https://github.com/rocker-org/rocker-versioned2)).
