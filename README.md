# SeuratDocker

This repository contains the source Dockerfiles for images with CRAN releases of Seurat.

As of tag `5.5.0` and pushes to `develop` and `latest` from 04/28/26, Seurat is built under R 4.5.2 under Ubuntu 24.04.4 LTS (Noble Numbat) with base image `rocker/tidyverse:4.5.2` ([reference](https://rocker-project.org/images/versioned/rstudio.html), [source](https://github.com/rocker-org/rocker-versioned2)).
